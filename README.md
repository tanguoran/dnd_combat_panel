# 即时战斗板（Live Battle Board）

一个面向线下面团的本地 H5 战斗板：DM 在跑团过程中即时拖图、画墙、放置 Token 和光源，玩家窗口只显示允许公开且处于视野内的内容。

## 已实现

- DM 控制台与无 UI 玩家画面双窗口
- `BroadcastChannel` 同机即时同步，无后端、账号或服务器
- PNG/JPG/WebP/GIF 拖放导入、分层、显隐、玩家可见性、锁定、缩放、旋转与复制
- Token 放置、框选、多选拖动、隐藏、复制/剪切/粘贴、视野来源与随身光源
- CAD 式连续墙体绘制，支持格点吸附和视野/光照阻挡
- 独立光源与玩家视野预览
- 平移、以鼠标为中心缩放以及屏幕/世界坐标转换
- IndexedDB 自动保存图片和场景，支持完整场景导入/导出
- 纯 TypeScript 场景模型与几何层；PixiJS 只负责渲染

## 本地运行

```bash
pnpm install
pnpm dev
```

打开终端显示的地址。DM 点击“打开玩家画面”，把弹出的窗口拖到电视或投影仪上；玩家窗口按 `F` 或双击进入全屏。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 选择 / 墙体 / Token / 光源 / 图片 | `V` / `W` / `T` / `L` / `I` |
| 平移 | 鼠标右键拖动，或中键拖动 |
| 缩放 | 鼠标滚轮 |
| 框选 / 追加选择 | 空白处左键拖动 / `Shift` + 选择 |
| 复制 / 剪切 / 粘贴 | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` |
| 选择全部 Token | `Ctrl+A` |
| 墙体格点吸附 | 绘制时按住 `Ctrl` |
| 结束墙体 | 右键、`Enter` 或 `Esc` |
| 玩家显隐 | 选中后按 `H` |
| 复制 | `Ctrl+D` |
| 旋转图片 | `R`；`Shift+R` 反向 |
| 删除 | `Delete` |
| 调整选中光源/视野半径 | `Shift` + 滚轮 |
